# AND Gate Architecture

## Overview

The design implements a 2-input AND gate.

## Inputs
- A: First logic input
- B: Second logic input

## Output
- Y: AND operation result

## Boolean Expression

Y = A & B

## Operation

The output is HIGH only when both inputs are HIGH.
For all other input combinations, the output is LOW.

## Hardware Architecture

Two input signals are connected to a
single AND logic function, producing one output.
